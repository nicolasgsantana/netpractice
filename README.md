## Description

NetPractice is a hands-on networking project from the 42 curriculum. Its goal is to learn how small networks are configured by fixing broken ones.

Using a web-based training interface, I completed 10 progressively harder levels by assigning correct IP addresses, subnet masks, routes and default gateways so that every host in each network can communicate as required.

## Instructions

### Running the training interface

1. Go to the `netpractice` directory.
2. Start the interface with the provided script:

   ```bash
   ./run.sh
   ```

   If the script is not executable, run `chmod +x run.sh` first.

3. Open the address printed in the terminal (or the interface page provided with the subject) in a web browser.
4. Insert my login, fill in the editable fields (IP addresses, subnet masks, routing table entries) and use the interface's check function to validate the configuration inside this repository.
You can also export your own configuration by using the button "get my config"

> This project was made using the version 1.9 of the netpractice interface
